# 第二阶段预览：中文用户控制台原型

- 状态：前端交互原型，待用户验收
- 技术栈：Vue 3、TypeScript、Vite
- 默认语言：简体中文（zh-CN）

## 本次交付

- 工作台总览：人格数量、Token 消耗、剩余额度、知识库文档数、使用趋势、资源概览和最近调用。
- 人格管理：列表、搜索、创建、编辑、启用/停用和删除；调用标识对应 OpenAI 兼容请求的 model 字段。
- 知识库：列表、创建、文档列表、本地文件选择交互和人格关联展示。
- API 接口：用户级 API Key 展示区、Base URL、认证方式、调用示例和可调用人格列表。
- 用量与账单：Token 趋势、输入/输出用量、调用明细和体验额度展示。
- 账户设置：账户资料、安全入口和通知偏好展示。
- 桌面端与移动端响应式布局，浅色品牌视觉，使用 SuperNova 渐变轨道标志。

## 重要边界

本阶段是可运行的前端交互原型，页面数据为演示数据。创建、编辑、删除、上传文件等操作只更新浏览器内存，不会写入数据库；API Key 为演示占位值，不能用于真实请求；当前 API 服务尚未提供身份、人格、知识库、计量等业务接口。正式联调前必须完成认证、租户隔离和服务端数据模型。

## 本地运行

通过 Docker Compose 启动后访问 http://localhost:5173。也可在 apps/console 目录运行：

    npm install
    npm run dev

生产构建：npm run build。
